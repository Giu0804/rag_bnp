# Answer Generation (Standard)

## Overview & Goal
This module is responsible for consuming the retrieved contexts (generated by the Context Creation module) and generating answers to user questions. It uses an asynchronous pipeline to communicate with any OpenAI-compatible API endpoint (such as vLLM or standard OpenAI). The main goal is to process large datasets quickly while supporting advanced LLM features, such as the `reasoning_effort` parameter for specific models (e.g., Qwen3-37B).

## Architecture
The architecture is designed for high throughput and stability. It leverages Python's `asyncio` combined with an `asyncio.Semaphore`. This acts as a concurrent batch-size limiter, ensuring that we send exactly $N$ simultaneous requests to the LLM server without overwhelming it. The pipeline automatically corrects parameter mismatches (like upgrading `reasoning_effort="high"` to `"xhigh"` if the target model requires it) and guarantees that the output dataset strictly maintains the same row order as the input dataset.

## File Structure
- `answer_generation.py`: Contains the `AnswerGenerator` class handling API calls, and the `run_answer_pipeline` asynchronous orchestrator. It handles input parsing, prompt formatting, error catching, and final dataset sorting.
- `notebook_no_citation.ipynb`: The execution notebook. It defines the parameters (temperature, max tokens, system prompt, batch size), loads the `.parquet` contexts, runs the generator, and saves the final answers.
